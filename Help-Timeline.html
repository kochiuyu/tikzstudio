Timeline Studio User Guide

Timeline Studio Walkthrough & Instructions

Build horizontal or vertical milestone timelines for historical documents, project plans, and academic papers.

1. Set Year Range & Scale

Specify the starting year, ending year, and pixel scale (e.g. 5 pixels per year). Choose horizontal or vertical orientation.

2. Add Milestone Events

Enter the numerical year and event description, then hit Enter or click Add Event. Events are automatically arranged and plotted along the time axis.

3. Generate & Export TikZ

Click Generate Timeline to draw. The TikZ code block updates in real time, ready to copy or download as a .tex file.
