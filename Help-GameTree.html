Game Tree Studio User Guide

Extensive Form Game & Decision Tree Guide

Build game theory models, sequential moves, imperfect information sets, and decision analysis trees. Export directly into compilable LaTeX TikZ code or open in Overleaf.

1. Node Archetypes

Decision Node ($P_i$)

Represents a strategic decision point where a specific player (e.g., $P_1, P_2, \text{Firm}, \text{Buyer}$) chooses among multiple actions.

Nature / Chance ($\mathcal{N}$)

Represents exogenous random events (e.g. Spence signaling worker types $\theta_H, \theta_L$, weather, market states) with associated branch probabilities ($p, 1-p$).

Terminal Node (Payoffs)

The game ends here. Displays the payoff vector $(u_1, u_2, \dots)$ or terminal outcomes (e.g. $(3, 1)$ or $(-c, \pi)$).

2. Highlighting Subgame Perfect Equilibrium (SPE)

To illustrate backward induction or equilibrium strategies:

  • Click on the node whose incoming branch is part of the equilibrium path.
  • Check the Equilibrium / Subgame Perfect Path checkbox in the inspector.
  • The canvas highlights the branch in bold red (eq_branch), and the generated TikZ code applies very thick, draw=red!80!black.

3. Imperfect Information & Information Sets

When a player cannot observe earlier moves made by an opponent or Nature (such as simultaneous moves in Matching Pennies or the Spence Job Market Signaling model):

  • Decision nodes at the same tree depth can be grouped into an Information Set.
  • In the canvas, they are connected by a curved dashed line.
  • In TikZ, they render as: 
    \draw[info_set] (n_1) to[bend right=15] node[midway, fill=white]{$I_1$} (n_2);

4. Compiling in LaTeX or Overleaf

To compile your diagram in a document: 

\documentclass{article}
\usepackage{amsmath,amssymb}
\usepackage{tikz}

\begin{document}

\begin{figure}[htbp]
  \centering
  % Paste your generated TikZ code here:
  \begin{tikzpicture}[...]
    ...
  \end{tikzpicture}
  \caption{Extensive-form game model}
\end{figure}

\end{document}
