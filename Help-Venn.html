Venn Studio User Guide

Venn & Euler Diagrams Guide

Master set theory notation, boolean algebra regions, probability unions, and compilable LaTeX TikZ code generation.

1. Fundamental Set Operations

In a 2-set or 3-set Venn diagram, the plane is partitioned into mutually disjoint atomic regions. Any mathematical event or expression corresponds to a union of these atoms:

Intersection ($A \cap B$)

Elements belonging to both set $A$ and set $B$. Represents logical AND and joint probability $P(A \cap B)$.

Union ($A \cup B$)

Elements belonging to $A$, $B$, or both. Cardinality satisfies $|A \cup B| = |A| + |B| - |A \cap B|$.

Relative Difference ($A \setminus B$)

Elements belonging to $A$ but NOT in $B$. Equivalent to $A \cap B^c$.

Symmetric Difference ($A \Delta B$)

Elements in either $A$ or $B$, but not both: $(A \setminus B) \cup (B \setminus A)$. Corresponds to logical XOR.

Complement ($(A \cup B)^c$)

Elements inside the universal set $U$ (or sample space $\Omega$) outside both circles. By De Morgan's Laws: $(A \cup B)^c = A^c \cap B^c$.

2. Interactive Placement, Locations & Cardinalities

  • Drag & Reposition Circles: Switch to the ✋ Move & Resize Sets tool on the canvas toolbar or drag any circle's center anchor directly on the canvas to freely relocate sets anywhere.
  • Interactive Resizing: Drag the border handle of any selected circle to resize its radius dynamically on screen, or type exact dimensions into the inspector.
  • Exact Coordinate Inspector: Use the Set Locations & Circle Inspector to fine-tune exact $(X, Y)$ coordinates, radii, stroke styles, and border colors per set.
  • Reposition Labels: Drag a set's name label to any custom offset angle or distance relative to the circle.
  • Click Any Region: In 👆 Shade Regions mode, click any region (e.g. $A \cap B$) to instantly toggle its shading on or off.
  • Arbitrary Euler Subsets: In Euler mode, freely move subsets inside or outside one another, or click + Add Set to introduce additional custom circles.

3. How TikZ Shading Works

The generator uses TikZ's powerful \begin{scope} ... \clip ... \end{scope} architecture. This ensures clean, portable compilation without requiring external PostScript packages or special engine flags: 

% Shading the intersection A \cap B in pure TikZ:
\begin{scope}
  \clip (-1.75, 0) circle (2.75cm); % Clip to Circle A
  \fill[purple!50, opacity=0.55] (1.75, 0) circle (2.75cm); % Fill Circle B inside clip
\end{scope}

% Draw outlines cleanly over the fills:
\draw[draw=blue!80!black, line width=2.5pt] (-1.75, 0) circle (2.75cm);
\draw[draw=red!80!black, line width=2.5pt] (1.75, 0) circle (2.75cm);

4. Exporting to Overleaf & LaTeX Documents

You can copy the code snippet directly into an existing document's \begin{figure} environment, or click Overleaf → in the toolbar to instantly generate and compile a full standalone document with all required preambles.
