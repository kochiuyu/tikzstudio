Flowcharts & State Machines Guide

Flowcharts, State Machines & Automata

Build computer science automata (DFA/NFA), business process flowcharts, algorithms, and transition diagrams with instant TikZ LaTeX export.

1. Standard Flowchart Shape Conventions

Terminal / Pill (Start & End)

Marks the entry and exit points of an algorithm, process, or workflow.

Process (Rectangle)

An operational action, computation, assignment, or task (e.g. x := x + 1).

Decision (Diamond)

A conditional branch asking a question (e.g. b = 0?) leading to Yes / No paths.

Data I/O (Parallelogram)

User input or system output operations (e.g. Read(a, b), Print Result).

2. Shape Connections, Anchors & Routing

Flowchart arrows and state transitions can be connected with precision using cardinal anchors and specialized routing patterns:

Interactive Port Snapping

Hover or select any shape to reveal the 4 cardinal ports (North / Top, South / Bottom, East / Right, West / Left). Drag from any port directly to another shape to snap into place.

Orthogonal Step Routing

Supports Smart Orthogonal, Vertical First (|-), and Horizontal First (-|), generating clean right-angle engineering pathways.

Feedback & Algorithm Loops

Use Feedback Loop (Left / Right) to route loopback branches cleanly outside the diagram hierarchy without overlapping other shapes.

Anchor Control & Label Placement

In the connection inspector, customize source and target anchors (.south, .north, etc.) and choose label position (Midpoint, Near Source, Near Target).

3. Finite State Machines (FSM) & Automata

TikZ Studio generates standard LaTeX code compatible with the automata TikZ library:

  • Initial State: Displays the incoming arrow indicator from the left (\node[initial]).
  • Accepting / Final State: Styled with concentric double concentric circles (\node[accepting]).
  • Transitions: Supports curved bidirectional edges (bend left, bend right) and self-loops (loop above, loop below).
  • Mathematical Labels: Input symbols such as 0, 1, \epsilon, or Mealy/Moore machine inputs/outputs a / b are automatically typeset in math mode.

4. Interactive Canvas Shortcuts

Key / Action Function
S or V Switch to Select & Move tool
A Activate Add Node tool
C Activate Connect tool (click source, then destination)
Del / Backspace Delete the currently selected node or connection
Double Click Directly edit the text of any node or connection
F Fit all elements to the canvas view

5. Compiling in LaTeX & Overleaf

Include the necessary TikZ libraries in your document preamble: 

\documentclass{article}
\usepackage{tikz}
\usetikzlibrary{shapes.geometric, arrows.meta, positioning, automata}

\begin{document}

\begin{figure}[htbp]
  \centering
  % Paste generated TikZ code here
\end{figure}

\end{document}
